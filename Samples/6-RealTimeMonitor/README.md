# Real-Time Monitor Sample

## Description
A complete real-time GPU monitoring application with console UI updates.

## What You'll Learn
- Multi-threaded monitoring
- Console UI updates
- Continuous data polling
- Production-ready patterns
- Graceful shutdown

## How to Run
```bash
cd Samples/6-RealTimeMonitor
dotnet run
```

Press ESC to exit.

## Features
- Live GPU temperature
- Energy counter
- Frequency tracking
- 1-second refresh rate
